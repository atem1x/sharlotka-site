# Кафе «Шарлотка» — сайт-визитка

Семейное кафе с собственной кондитерской · ул. Фруктовая, 8, пгт Авангард (Одесская обл.) · +380 67 925 58 62 · [@sharlotka_family_cafe](https://www.instagram.com/sharlotka_family_cafe/)

Одностраничный статический сайт без сборки: открывается двойным кликом по `index.html` и работает на любом хостинге (GitHub Pages, Netlify, Cloudflare Pages). Украинский язык по умолчанию (требование закона о языке), русский — переключателем UA/RU.

## Что где лежит

| Файл | Что внутри | Кто правит |
|---|---|---|
| `site-config.js` | телефон, email, адрес, ссылки, часы работы, объявление, мессенджеры, показ цен, фото Instagram-блока | владелица — без программиста |
| `menu-data.js` | всё меню: категории, блюда UA/RU, цены, вес, метки «хвалят гости» / «для вегетарианцев» | владелица |
| `i18n.js` | все тексты сайта на украинском (`uk`) и русском (`ru`) | по необходимости |
| `index.html` | разметка + украинский текст для посетителей без JavaScript, SEO-теги, JSON-LD | разработчик |
| `styles.css`, `main.js` | оформление и интерактив | разработчик |
| `assets/img/full`, `assets/img/thumb` | фото кафе (большие / превью) | — |
| `assets/img/instagram/` | сюда класть свежие фото для блока Instagram (см. README.txt там же) | владелица |

Подсказки на украинском и русском есть прямо в начале `site-config.js` и `menu-data.js`.

## Частые правки

- **Цены.** `menu-data.js` → `price: 95` или `price: [80, 120]` (две цены, например 350 г / 1 кг). Спрятать все цены: `showPrices: false` в `site-config.js`.
- **Объявление** (праздничный график, свет по графику): `announcement` в `site-config.js`; пусто — не показывается, `until` — дата, после которой оно исчезнет само.
- **Мессенджеры** в «Записке Шарлотте Моисеевне»: `messengers` в `site-config.js`. Вписывать только реально подключённые к номеру кафе.
- **Выходной или другие часы в какой-то день:** `hours.byDay` в `site-config.js` (пример в комментарии). Статус «Открыто / Закроемся через N минут / Закрыто» пересчитается сам.
- **Свежие фото в блок Instagram:** положить файлы в `assets/img/instagram/` и прописать их в `instagramPhotos`.

После правки — сохранить файл и обновить страницу. Если сайт уже на GitHub — закоммитить и запушить, через минуту изменения будут на сайте.

## Публикация на GitHub Pages со своим доменом (как skyprimal.dev)

1. Создать публичный репозиторий `sharlotka-site` и запушить содержимое этой папки (папка `_variants/` исключена в `.gitignore`).
2. Settings → Pages → *Deploy from a branch* → `main` / `/ (root)`.
3. Домен: файл `CNAME` в корне с одной строкой — доменом (например, `sharlotka.od.ua`). Затем Settings → Pages → *Enforce HTTPS*.
4. DNS у регистратора домена:
   - корневой домен → четыре `A`-записи: `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`;
   - `www` → `CNAME` на `atem1x.github.io`.
5. В `index.html` заменить `YOUR-DOMAIN` на домен и раскомментировать блок `canonical / hreflang / og:url` (комментарий в начале `<head>`), сделать `og:image` полным адресом; в `robots.txt` раскомментировать строку `Sitemap` и добавить `sitemap.xml`.
