Кладіть сюди фото для блоку Instagram, напр. 01.jpg, 02.jpg…
Потім впишіть їх у site-config.js → instagramPhotos, напр.:
  { src: "assets/img/instagram/01.jpg", w: 1280, h: 1600, alt: { uk: "…", ru: "…" } }
w і h — ширина й висота фото в пікселях. Перше фото показується великим.
